# Incident response
For suspected refresh-token theft, revoke the affected session using the existing session API. Reuse revokes the whole session automatically. Password changes invalidate existing sessions. For scanner failures restore the private ClamAV service and signature updates; never bypass scanning. Audit records distinguish clean and rejected scans without retaining file contents.

A complete administrative Security Center, incident state machine, alert delivery and investigation history remain outstanding. Restrict access to deployment logs and secrets, rotate compromised credentials, preserve sanitized evidence, and validate recovery before restoring production access.
